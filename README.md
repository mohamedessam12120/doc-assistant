# Company Policy Assistant

## Problem
Employees repeatedly ask HR the same questions (leave, working hours, benefits)
and struggle to search long policy PDFs.

## Goal
Employees ask in natural language and get an answer with its source
(document and page). If the answer is not in the documents, the assistant
says it does not know instead of guessing.

## Success metrics (targets, to be measured)
- At least 85% correct answers on a 30-question evaluation set
- Out-of-scope questions are answered with "I don't know", not invented answers

## Data
Fictional policy documents only. No real company data.

## Out of scope for v1
Voice, user accounts, document upload UI.
